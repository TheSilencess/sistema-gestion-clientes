# Matriz inicial de paridad

| Área | Implementación actual | Falta para equivalencia completa |
|---|---|---|
| Clientes | Alta, edición, NIT, contacto, clasificación, responsable, dirección | Reglas por perfil, relaciones heredadas completas |
| Productos | Variantes, múltiples usos, precios, stock manual | Catálogos originales completos, automatización exacta de inventario |
| Ventas/envíos | Documentos, partidas, entrega, guías, empresas, totales | Estados con efectos de negocio, FEL, conversión a compra, diseños originales |
| Pagos | Abonos nuevos, anulación y saldo; histórico separado | Contraste con las tres funciones originales |
| Compras | Proveedores, crédito, vencimiento, partidas y saldo | Automatización original de inventario y saldos |
| Proveedores/asesores | Altas, edición, referencias y campos personalizados | Matriz de permisos y datos completos |
| Documentos | Archivos locales/R2, hashes, descarga, comentarios | Importación masiva de archivos y relaciones históricas |
| Informes | Ocho vistas, filtros básicos, CSV, impresión | Fórmulas/agrupaciones exactas, programación y Excel nativo |
| PDF | Impresión comercial para guardar desde navegador | Once plantillas exactas y firma/certificación FEL |
| Migración | CSV, mapeo, simulación, atomicidad, IDs, originales y lote | Extractor SQL/API, carga masiva, conciliación final y pruebas de volumen |
| Seguridad | Espacio local único; identidad Sites prevista en servidor | Personal, perfiles, reglas por campo y permisos efectivos |
| Correos y tareas | Estado pendiente visible | Conectar proveedor, plantillas, colas y planificador |
| Acciones de lista | Búsqueda, filtro, orden, selección/exportación, vistas | Edición masiva y herramientas avanzadas de combinación |

No se declara equivalencia completa ni habilitación para reemplazar producción en esta entrega.
